# Epic Explorer 

Epic Explorer is a travel information web application that allows users to explore different tourist destinations across India.

## Features
- Region based travel discovery
- North, South, East, West and Central India navigation
- Image cards with destination details
- Responsive design using Bootstrap

## Technologies Used
HTML
CSS
JavaScript
Bootstrap

## Project Structure
index.html – main webpage  
style.css – UI design  
script.js – dynamic region display logic  

## How to Run
1. Download or clone the repository
2. Open index.html in your browser
